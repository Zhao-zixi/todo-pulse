# 待办节拍 · Todo Pulse

一个中文、单用户的 AI 待办 Web App。用一句话生成草稿，核对后保存；也可以直接填写。支持指定时间提醒、按分钟重复，标记完成后停止后续提醒。

## 在本机运行

需要 Node.js 24 或更新版本。

```sh
git clone https://github.com/Zhao-zixi/todo-pulse.git
cd todo-pulse
npm ci
npm start
```

打开 **http://localhost:3000**。先试「明天晚上 8 点提醒我倒垃圾，每隔 10 分钟提醒一次」，检查草稿时间后保存。也可以只填一个间隔，例如每 3 分钟提醒一次；第一次在保存后 3 分钟到期。SQLite 在本地保存待办，重启不丢失；重复任务漏过多次时会合并为一次，不会一口气补发。

## 接入 AI 助手

可不配 AI 先试用，本地规则只识别常见的时间和间隔说法。配置支持 Chat Completions 的服务后，生成草稿才会调用该服务；应用不会把已有任务列表发送给模型。

在项目目录创建本地 `.env`：

```dotenv
AI_BASE_URL=https://api.openai.com/v1
AI_API_KEY=替换成自己的密钥
AI_MODEL=替换成服务支持的模型名
```

密钥仅由服务端读取，不要提交 `.env`。点击「生成草稿」时，输入的描述及用于解释时间的上下文会发送到你配置的 AI 服务。AI 不会自动保存或更改待办。

## 提醒方式

- 默认在打开页面时轮询，提醒显示在「最近提醒」。点击「开启通知」授权后，可用浏览器支持的系统通知。
- 如需离开页面后仍可提醒，在 `.env` 设置 `TODO_WEB_PUSH=1`，设置有效的 VAPID 联系方式（例如 `VAPID_SUBJECT=mailto:your-address@example.com`），重启服务器，在每台设备上重新点击「开启通知」。推送密钥保存在 SQLite；重建数据库后需要重新订阅。
- 远程访问要求 HTTPS；本机开发可用 localhost。iPhone / iPad（iOS / iPadOS 16.4 及以上）需先将页面添加到主屏幕，再在主屏幕 App 里开启通知。浏览器及系统必须支持并允许 Web Push；系统省电、勿扰模式或设备离线都可能影响送达。Node 服务必须常驻运行。浏览器推送服务会接收加密通知；支持锁屏通知的设备可能显示待办标题。
- 推送是尽力送达，不适用于必须准时收到的紧急提醒。未开通或本次未送达时，仍可回到页面查看近期记录。

## 使用范围

默认只监听本机 `127.0.0.1:3000`。这是一套单用户应用，尚未内置登录。若要从手机访问，应先使用受访问控制的 HTTPS 入口，并保持运行 Node 的机器在线；不要直接把端口暴露在公网。若反向代理保留原域名作为 Host，在 `TODO_ALLOWED_HOSTS` 添加该域名（逗号分隔，不含协议和端口）。GitHub 上的公开源码不等于已部署的应用。

`PORT` 可改端口；`TODO_DB_PATH` 可指定 SQLite 路径。请让 SQLite 文件所在目录保持可写并定期备份。
